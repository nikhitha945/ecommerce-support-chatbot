# Canceling an Order

You can cancel an order yourself within **1 hour of placing it**: go to Order History, open the order, and select "Cancel Order." The authorization hold on your card is released immediately and no charge is captured.

After the first hour, the order may already be in the warehouse queue. Contact support as quickly as possible — if it hasn't shipped yet, we can usually still stop it.

Once an order has shipped, it **cannot be canceled**. In that case, wait for delivery and use the standard 30-day return process instead; return shipping is on us if the cancellation request was made before shipment.

Pre-orders can be canceled any time before the release/ship date from Order History.
