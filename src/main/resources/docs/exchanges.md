# Exchanges

Need a different size or color? Exchanges are handled as a **return plus a new order** to keep things fast: start a return for the original item from Order History, then place a fresh order for the variant you want. This avoids waiting for the warehouse to process the return before the new item ships.

Exchanges follow the same **30-day window** and condition rules as returns. If the new item costs more, you pay the difference at checkout; if it costs less, the difference is refunded to your original payment method per the refund timeline.

One shortcut: if the item is defective or the wrong item was sent, use the damaged-or-defective claim process instead — replacements ship express at no charge and you skip the reorder step.
