# Promo Codes and Discounts

Enter your promo code in the "Discount code" box on the cart page **before** checkout. The discount applies immediately and shows as a line item.

Rules to know:

- Only **one promo code per order**. Codes cannot be combined or stacked.
- Codes are not case-sensitive, but must be entered without spaces.
- Most codes exclude gift cards, shipping fees, and items already on clearance.
- Each code has an expiry date; expired codes show "This code is no longer valid" at checkout.

If a valid code isn't applying, check that your cart meets the minimum spend shown in the promotion terms, and that none of the items are excluded. Codes from third-party coupon sites are often expired or fake — only codes from BrightCart emails or the site itself are guaranteed.
