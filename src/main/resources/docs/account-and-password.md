# Account and Password

You can check out as a guest, but creating an account lets you track orders, save addresses, and start returns in one click. Create one from the "Sign Up" link or automatically at checkout by ticking "Create an account."

If you forget your password, use the "Forgot password" link on the sign-in page. A reset link is emailed to you and **expires after 15 minutes** — request a new one if it lapses. Check spam if it doesn't arrive within a few minutes.

For security, passwords must be at least 10 characters and include a number. After five failed sign-in attempts, the account locks for 15 minutes; use the reset link rather than guessing repeatedly.

To update your email address or delete your account, go to Account Settings. Deleting an account is permanent and removes order history visibility, so download any invoices first.
